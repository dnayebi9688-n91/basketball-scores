# راه‌اندازی (۵ دقیقه، رایگان)
1. در GitHub یک repo عمومی بسازید و همه این فایل‌ها (با پوشه .github) را آپلود کنید.
2. Settings → Pages → Source: «Deploy from branch» → main / root.
3. تب Actions → «update-scores» → Run workflow (بار اول دستی). از آن به بعد هر ۱۰ دقیقه خودکار اجرا می‌شود.
4. آدرس سایت: https://USERNAME.github.io/REPO/
